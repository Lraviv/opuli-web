# אפליקציית עזר לסטודנטים — Monorepo

- `backend/` — Python + FastAPI (ראו `backend/README.md` להוראות הרצה מקומית)
- `mobile/` — React Native / Expo (יתווסף בשלב הבא)

## סטטוס נוכחי

הבאקנד מומש במלואו: הרשמה/התחברות (JWT), תארים וקטלוג קורסים, קורסים אישיים, פריטי התקדמות, מבחנים עם תזכורות, טוקני Push, ו-endpoint פנימי לשליחת תזכורות. מכוסה בסוויטת pytest. אפליקציית המובייל תתווסף בשלב הבא.
